# Little Explorers — Agent Rules

Read docs/Little_Explorers_Product_Engineering_Blueprint.md before making product or architecture changes.

Rules:
- This is a new app. Do not reuse JapamApp code.
- Keep child UX visual, simple, playful, and low-text.
- Every island should feel like a small world, not a quiz.
- Keep learning content separate from UI logic where practical.
- Do not add Supabase, authentication, payments, or production integrations without explicit approval.
- Do not make product-level decisions when the blueprint is silent; ask first.
- Prefer small, testable increments.
- Report files changed and tests run after implementation.
